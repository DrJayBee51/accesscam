# Hardware

SolidWorks source files and exported STL/STEP files for the camera housing and
monitor mount live here.

- `solidworks/` — native `.sldprt` / `.sldasm` sources
- `stl/` — exported meshes ready for slicing

See [../docs/HARDWARE.md](../docs/HARDWARE.md) for the design requirements the
housing must satisfy (photoresistor shroud, filter slot, aiming adjustment).
